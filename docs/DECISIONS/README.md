# Decisiones (ADR) — task-dashboard-IA

Nivel 3 de `/td-learn`: **solo decisiones cerradas e inmutables**, una por archivo
`ADR-NNNN-<tema>.md`. Barrera altísima: se propone y se confirma con el usuario antes de escribir.
Un ADR aceptado no se reescribe; el aprendizaje nuevo es un ADR nuevo que lo enlaza.

Todavía no hay ninguno. Las decisiones de arranque (Railway, un solo servicio, Postgres, identidad
por token) están en [CONTEXTO-INICIAL.md](../CONTEXTO-INICIAL.md) y pasan a ADR cuando se cierren
con Andrés — hasta entonces son "dirección acordada, a validar".
